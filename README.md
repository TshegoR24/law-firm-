# Nabane Inc — website sample

Demonstration website for **Nabane Inc** (Walter Nabane Incorporated), a legal and advisory practice in Capital Park, Pretoria. Built with Next.js (App Router), TypeScript, Tailwind CSS, Lucide and Framer Motion.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm start        # serve the production build
```

## Where to edit

- `src/config/site.ts` — firm name, address, phone, WhatsApp number, hours.
- `src/data/practice-areas.ts` — practice area pages.
- `src/data/attorneys.ts` — team profiles.
- `src/data/articles.ts` — sample insight articles (pending attorney review).
- `src/lib/images.ts` — swap the architectural illustrations for real photography.

## Notes

- The consultation form is a front-end demonstration; nothing is sent.
- An email address and the team biographies/photos have not been supplied yet.
- Confirm the WhatsApp number is WhatsApp-enabled before launch.
